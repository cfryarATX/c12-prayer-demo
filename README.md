# C12 Prayer demo

A clickable demo of the C12 Prayer app for iPhone, with fictional sample data only.
All names are made up, all emails are @example.com, and no email is ever sent.
Changes are saved only in your own browser. Use "Reset demo" at the top to start over.
Use "Log out" at the top to lock the demo again on your device. Your changes are kept.

The passcode screen is a light gate to keep casual visitors out. It is not real security, so this repo holds no real data.
